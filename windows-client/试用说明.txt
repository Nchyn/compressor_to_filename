JPEG 剪贴板 Windows 试用版 0.1.0

适用：Windows 10/11 x64。无需安装 Node.js、Python、.NET 或 WebView。
此文件为 macOS 交叉编译试用版，尚未在真实 Windows 上验收，未签名。

1. 将 EXE 复制到 Windows 本地目录，双击运行。
2. 检查网页地址。默认 https://cpr.adwetec.nchyn.net 。如果使用其他域名，请修改后点击“保存并重启”。
3. 点击“打开压缩器”，按浏览器提示允许本地网络访问，确认网页连接指示灯变绿。
4. 粘贴图片后，网页压缩，客户端仅保存并复制文件；可到资源管理器或目标聊天软件粘贴验证。
5. 文件夹测试请使用副本！网页可能在您确认并授权后覆盖源文件。客户端保存网页生成的原始 ZIP，不重新打包。
6. “再次复制”成功后按钮显示“已复制”。多张图片依次复制时，剪贴板最终是最后一张。
7. “打开缓存”可查看文件；“清除缓存”确认后删除旧文件，保留剪贴板当前引用文件。
8. 关闭窗口即退出客户端。文件保留在当前用户 LocalAppData\JPEGClipboardWindows\Cache。

限制与提示：
- 未签名程序可能出现 SmartScreen 提示；如系统/公司策略拦截，请不要关闭全局安全防护，先反馈提示内容。
- 仅支持在线 HTTPS 网页，或 localhost HTTP；不开放任意 Origin。
- 浏览器本机网络访问策略可能需要单独授权。
- 原型服务一次处理一个请求；异常中断或不完整上传可能使服务停留在停止中。关闭客户端并重新打开可恢复。
- 本机二进制检查不能证明剪贴板在所有目标软件中可用，请反馈截图或错误日志。

本试用包不修改 Mac 客户端，不自动部署网页，不提供自动更新。
